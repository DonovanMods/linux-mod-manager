lmm · Linux Mod Manager

Manage your game mods on Linux.

lmm installs, updates and organizes your game mods through a local web UI or the terminal. Keep separate profiles for solo play, co-op, or trying something new.

Install lmm Read the guide

Free and open source under the MIT license. One binary for x86-64 and ARM64 Linux.

Save a setup. Make the game match it.

A profile records your mods, versions and load order. Applying it installs what's missing, removes mods it no longer lists, and changes versions in either direction. Version locks stay enforced.

Keep separate profiles for solo and co-op play. Switch between them using the mod files lmm already has in its cache.

Export a profile as YAML to save or share the setup. Another computer can fetch the same versions when its sources are configured and those files are still available. Keep local mod archives and custom-source configuration separately: the profile doesn't include them. How profiles work.

$ lmm profile export default > setup.yaml
$ lmm profile apply --dry-run

A terminal and a browser, one engine

Browse your library, find mods and manage updates in the web UI. Use the CLI for scripts or over SSH. Both use the same engine, database and profiles.

Run lmm serve to open the UI in your browser. It listens on your computer's loopback address by default, and can run as a systemd user service. Run lmm in the background.

Bring your games and your mod sources

lmm finds Steam games and Battle.net installations under Wine or Proton, and fills in mod paths for known games. Already modded a game? Scan its mod folder to bring existing mods into lmm. Get started with your games.

  • NexusMods and CurseForge

    Connect with an API key, stored encrypted on your computer. Free NexusMods accounts can import manually downloaded archives.

  • Thunderstore

    Browse without an API key. For BepInEx games such as Valheim and Lethal Company, lmm puts plugins where the loader expects them.

  • Steam Workshop

    Track the items Steam already installed, import a Workshop collection as a profile, or let lmm download an item and manage its own copy.

  • Your own sources

    Describe a local folder, a JSON or YAML mod list, or a REST API in a short YAML file. lmm installs and updates from it like a built-in source.

  • Files you downloaded

    Hand lmm an archive you downloaded yourself, for example from a free NexusMods account, and it manages that mod like any other.

  • Icarus

    Icarus has its own built-in source. lmm converts its .pak mods and merges them in load order.

Preview changes and keep a way back

Review installs, updates and profile changes
The web UI shows a plan before installing, updating, deploying or applying a profile. In the CLI, update, deploy and profile apply support --dry-run. Enabling or disabling a mod applies immediately.
Back to an unmodded game
lmm purge removes deployed mods and restores originals backed up when lmm replaced game files.
Snapshots and rollback
Save a snapshot of your mod setup before experimenting. lmm update rollback can return a mod to its previous version.
Verify what's on disk
lmm verify checks cached files and the deployed mod files. lmm conflicts shows which mods provide the same file and which one wins.

Fits the way you use Linux

Ready for scripts

Add --json for structured command output, with warnings inside the document. Use it with jq or your own tools. JSON output reference.

$ lmm update --json | jq '.updates'

Verified self-updates

Release-download and go install installations can update automatically after signature and checksum verification. You can turn this off. Package installations stay under your package manager's control. How updates work.

Check that lmm fits your setup

FOMOD installer options, automatic LOOT-style plugin sorting and Nexus Collections aren't supported yet. You can set load order yourself. The web UI is designed for desktop browsers. Check the compatibility FAQ.

Install lmm

Every release on GitHub Releases has packages and a plain download for x86-64 (amd64) and ARM64 (arm64).

Debian, Ubuntu, Fedora, openSUSE, Alpine

Download the .deb, .rpm or .apk from the latest release, then install it:

# Debian / Ubuntu
sudo dpkg -i lmm_<version>_linux_amd64.deb
# Fedora
sudo rpm -i lmm_<version>_linux_amd64.rpm
# openSUSE
sudo zypper install ./lmm_<version>_linux_amd64.rpm
# Alpine
sudo apk add --allow-untrusted ./lmm_<version>_linux_amd64.apk

Includes the man pages and shell completions.

Arch Linux

Each release carries a PKGBUILD for lmm-bin. It isn't on the AUR yet (#549).

mkdir lmm-bin && cd lmm-bin
curl -LO https://github.com/DonovanMods/linux-mod-manager/releases/latest/download/PKGBUILD
makepkg -si

Any Linux

Download lmm_<version>_linux_amd64.tar.gz (or arm64) and put lmm on your path. Installed this way, lmm updates itself.

tar -xzf lmm_*.tar.gz
mkdir -p ~/.local/bin && mv lmm ~/.local/bin/

With Go

Needs Go 1.27 or later.

go install github.com/DonovanMods/linux-mod-manager/v2/cmd/lmm@latest

Then run lmm serve and follow the setup in your browser, or lmm init in the terminal. The guide walks you through adding a game and installing your first mods.
