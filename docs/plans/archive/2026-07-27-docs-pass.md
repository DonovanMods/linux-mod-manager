# Docs Pass Implementation Plan (EPIC #104 — Documentation)

**Goal:** Close EPIC #104's Documentation section: man pages current and complete for every command, README/configuration.md/CLAUDE.md audited back to reality, exit codes documented, `--help` surface fixed, link_method precedence honestly documented — and (user decision 2026-07-27) man pages become **generated from the Cobra command tree** so this drift cycle can't recur.

**Strategy shift (user-approved):** the 13 existing man pages are hand-written roff, uniformly dated 2026-01-29, untouched across ~19 releases. Rather than hand-editing 13 and hand-authoring 5 more, the Cobra help text (`Short`/`Long`/flag usage strings) becomes the single source of truth; a hidden `gen-man` command + `make man` target regenerates `docs/man/man1/`; a drift test fails CI whenever help text changes without regeneration. All content gaps found by the audit are therefore fixed **in the help text**, improving `--help` and the man pages in one stroke.

**User decisions (2026-07-27):** PRD.md → archive to `docs/plans/archive/`; man tooling → wire `cobra/doc.GenManTree` NOW (not deferred); `.goreleaser.yaml` ships `docs/man/**` in release archives.
